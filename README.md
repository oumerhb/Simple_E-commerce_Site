# Habeshan Treasures - Ethiopian E-commerce Website

A modern, single-page e-commerce website showcasing Ethiopian cultural items including spices, pottery, textiles, and coffee. Built with vanilla HTML, CSS, and JavaScript.

## Features

- Responsive single-page design
- Product filtering by category
- Shopping cart functionality with localStorage persistence
- Product quick-view modal
- Checkout process
- Mobile-friendly design
- Newsletter subscription
- Testimonials slider

## Project Structure

```
habeshan-treasures/
├── index.html          # Main HTML file
├── css/
│   └── style.css       # Main stylesheet
├── js/
│   ├── app.js          # Main JavaScript functionality
│   └── products.js     # Product data
└── images/             # Product and site images
```

## Setup Instructions

1. Clone or download this repository
2. Open `index.html` in a web browser

No build process or server is required as this is a static website using only HTML, CSS, and vanilla JavaScript.

## Adding Real Images

Before deploying to a live environment, replace the placeholder images with actual product images:

1. Add a hero image as `images/hero.jpg`
2. Add an about section image as `images/about.jpg`
3. Add category images as `images/spices.jpg`, `images/pottery.jpg`, `images/textiles.jpg`
4. Add product images named `images/product1.jpg` through `images/product15.jpg`
